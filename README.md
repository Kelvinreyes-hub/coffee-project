# Coffee Learning Hub

This is a self-contained, pixel-art coffee education game. It animates page turns directly inside the coffeehouse scene and includes Learning, Employment, Involvement, plus About & Contact and News.

Every topic now has its own standalone pixel-art illustration in `assets/page-art/`. Those images use transparent padding and are placed with `object-fit: contain`, so they sit cleanly inside the book page instead of being cropped from a larger sheet.

## Run it in VS Code

1. Open this folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and select **Open with Live Server**.

You can also open `index.html` directly in a web browser. No npm packages or build steps are required.

Use the illustrated shelf books, the header tabs, or the page buttons. PREV/NEXT (or the left/right arrow keys) changes the topic page. Module buttons are intentionally blank lesson placeholders for future learning content.
